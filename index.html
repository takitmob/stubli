Synchronisation via GitHub

Tes données sont sauvegardées automatiquement dans ton navigateur (hors-ligne). Pour les retrouver sur tous tes appareils, connecte un dépôt GitHub : l'app y écrit un fichier progress.json à chaque sauvegarde, via l'API GitHub — directement depuis ton navigateur, sans aucun serveur tiers.

Crée un fine-grained token limité à ce seul dépôt, permission "Contents: Read and write". Le token reste uniquement dans ton navigateur (localStorage) et n'est envoyé qu'à api.github.com. Créer un token →
